- `face_thinking_1.png` ...   – thinking animation (2–4 frames)
- `face_talking_1.png` ...    – talking animation
- `face_happy.png`
- `ui_chat_bg.png`            – chat background
- `ui_button.png`             – buttons
- `icon.png`                  – plugin icon

## Recommendations

- Face resolution: ~64×64 or 96×96 pixels
- Style: cute, pixel art or clean (your choice)
- Adjust color palette to 3DS color space (limited colors)
- Later convert with `tex3ds` or a custom converter to .bin / .t3x
